## 怎么打开

1. 电脑：双击 `index.html`，或把此目录拖进 VS Code 用 Live Server 预览。
2. 在所有设备用网址打开：把整个 `study-planet` 文件夹内容上传到一个 GitHub 仓库根目录，进入仓库 `Settings → Pages → Deploy from a branch`，选择 `main / (root)`，保存后使用生成的 HTTPS 地址。
3. iPad / iPhone / 电脑可打开同一网址；在 Safari 中点分享 → 添加到主屏幕，就像一个学习 App。

## 关于进度（请先看）

网站为不需要后端的静态网页，待办、题目状态、八股掌握、实验指标、投递记录和复盘都用浏览器 `localStorage` 保存。**它不会自动跨设备同步，也没有账号登录**。在 A 设备导出 JSON，在 B 设备导入，可手动迁移进度。不同设备直接访问同一网址不等于进度同步。请不要在公开仓库上传进度 JSON（可能包含个人投递记录等）。

## 课程结构

- `今日学习`：项目任务、当天 Hot 100、1 张八股问答和求职动作，含官方资料与可检查的输出。
- `学习航线`：62 天任务与投递/考试时间节点，可直接跳某一天。
- `项目实验室`：RepoLens Code RAG + Agentic Retrieval；MediaFlow 动态 Agent + 审核/发布/恢复；量化实验占位记录。
- `Hot 100`：100 道力扣题目、官方题面链接、状态追踪。
- `八股训练室`：38 道 RAG、Agent、Python、数据库、操作系统、网络、工程和行为面试问答，先自测再翻答。
- `面试与投递`：技术面清单、STAR 素材、简历验收、投递日志。
- `资料星库`：30 条可直接打开的学习资料，标明要看什么。
- `复盘与数据`：每日记录、每周复盘、JSON 备份/恢复。

## 工程边界

- 网站是学习管理工具，**不自动执行 Codex / 跑代码 / 评估 LeetCode / 读取 GitHub commit / 自动投简历**。
- 学习版中的数值【XX】均保留为目标，完成实验后才填写；Mock 发布与真实平台权限必须标清。
- RepoLens 只读分析固定 commit 的 GitHub 源码，暂不执行不可信仓库代码。
- 资料与题目链接依赖外部站点网络权限；核心站内内容静态可用。
